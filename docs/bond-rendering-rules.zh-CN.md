# ChemSema 键绘制规则

本文档记录当前 Rust 渲染内核中的键绘制和键接触规则，固定几何定义、实现边界和重构基线。

本文档中的 “应 / 必须 / 不得” 都是规范性要求；“可以 / 允许” 是实现可选空间。

## 目标

- 键绘制应由 Rust 内核统一定义，不依赖 viewer 的二次修补。
- 同类键应尽量共享几何模型，减少按键型拆散的局部启发式。
- 节点接触应优先由轮廓和端点 profile 决定，避开 SVG `linecap` 或前台样式带来的偶然形状。
- 预览态和落地态应复用同一套几何。

## 适用范围

- 本文档只约束 fragment 路径。
- `legacy molblock` 路径只要求兼容输出，不要求逐条满足本文档中的新几何规则。
- 本文档描述 2D 几何输出。前台交互状态管理、hover 装饰和选中框样式由交互层文档约束。

## 术语

- 主键：决定键接触和节点占位的主轴母体。
- 副线：单侧双键和三键中，相对主键偏移的附属线。
- 母体：未被 knockout 切段之前的完整 polygon。
- 端点 profile：某根键在某个端点真正吃掉的轮廓链，最终参与 polygon 收口。
- 保持原样：保持该键标准母体外框，不为了接触去改端帽轮廓。
- 退让：不改外框拓扑，只沿轴向缩短或后退，使该键不压进接触对象。
- 同侧：相对于节点局部法向，副线或外线位于与当前参考线相同的一侧。
- 直通：两根轴线近似 `180°` 反向共线的情况。

## 总体分类

当前键分成三类：

1. 有主键的对象。
2. 无主键但有固定母体形状的对象。
3. legacy molblock 路径。

本文档只讨论 fragment 路径中的前两类。

### 有主键的对象

- 普通单键
- 粗实键
- 普通虚键
- 哈希键
- 单侧双键
- 中心双键
- 三键
- 实锲形键
- 虚锲形键

### 统一几何口径

- 所有实键都按 polygon 处理。
- 普通单键和粗实键几何本质相同，只是宽度不同。
- 实锲形键按梯形处理。窄端是一条很短的边。
- 普通虚键是“母体 polygon + 白色 knockout 切段”。
- 哈希键是“粗实母体矩形 + 更密的白色 knockout 切段”。
- 虚锲形键是“实锲形母体梯形 + 白色 knockout 切段”。

## ChemDraw 绘图模板参数

Default 和 ACS Document 1996 使用两套独立模板参数。切换模板时，已有键和后续新键都应同步切换模板参数。

当前对齐 ChemDraw 的关键差异：

| 参数 | Default | ACS Document 1996 | 说明 |
| --- | ---: | ---: | --- |
| 键长 | `30.0pt` | `14.4pt` | 切换模板时按该比例缩放现有结构几何 |
| 普通线宽 | `1.0pt` | `0.6pt` | 用于普通键、窄端锲形键和图形线宽 |
| 粗键宽 | `4.0pt` | `2.0pt` | 粗实键模板宽度 |
| 实/空心锲形宽端 | `6.0pt` | `3.0pt` | 为 `1.5 * BoldWidth`；空心锲形键与实锲形键共用轮廓 |
| label clip 自然外扩 | 源 `MarginWidth` | 源 `MarginWidth` | 来自源模板的绝对 pt 值；不随 label 字号缩放 |
| label clip 圆半径 | `2 * MarginWidth` | `2 * MarginWidth` | 从源模板 margin 派生的绝对 pt 值 |
| hash spacing | `2.7pt` | `2.5pt` | hash 家族的模板间距 |
| bond spacing | `12%` | `18%` | 双键间距百分比，与实际键长和线宽下限一起使用 |
| margin width | `2.0pt` | `1.6pt` | 非端点键键交叉时，上层键周围的白边宽度 |

锲形键宽端、label clip 自然外扩、label clip 圆半径和 margin width 都属于模板参数，不应从键长反推。CDXML 导入时，实/空心锲形宽端按源模板 `BoldWidth` 的 1.5 倍派生，label clipping 数字直接使用源模板；不得根据 `MarginWidth` 反推出所谓 ACS label clipping 模式。

CDXML 导入时，label clipping geometry 由源 `MarginWidth` 参数化：自然外扩严格等于 `MarginWidth`，圆形锚点半径严格等于 `2 * MarginWidth`。这两个值都是绝对 pt，不得再乘 label 字号或 glyph 高度。

## 统一判定顺序

每个 bond 端点都应按以下顺序求最终 geometry：

1. 先确定该键的标准母体形状。
2. 如果节点有 label，先执行 label clipping。
3. 再决定该端点是否进入节点接触规则。
4. 如果进入接触，再按键型选择：
   - 主键求交
   - 副线求交
   - 只退让
   - 保持原样
5. 在最终母体上叠加 dash/hash/knockout。
6. 预览态与落地态必须走同一套流程。

任何实现都不得把 viewer 的 stroke、line join、line cap 当成几何定义的一部分。

## 主键接触

“主键接触”指接触区由主键轮廓决定。

### 两根键接触

适用于普通单键、粗实键、普通虚键、哈希键、单侧双键主键、三键主键、实锲形键主轴、虚锲形键主轴等“有主键”的情况。

规则：

1. 两根键在节点处共享一个中心点。
2. 每根键在该端点都有两条主键轮廓线。
3. 计算两根键的 `inner-inner` 交点和 `outer-outer` 交点。
4. 这两个交点组成接触区边界。
5. 每根键吃自己的端点 profile，直接生成自己的 polygon，不靠额外遮罩补丁修形。

补充：

- 这里的交点允许使用延长线，不要求交点落在线段原始长度内。
- ChemDraw 的锐角 miter limit 是相对于键可用长度的限制，不是固定角度，也不是固定线宽倍数。对每条参与求交的轮廓，交点沿该轮廓的投影绝对值必须同时满足 `|projection| <= 0.235 * extent`。`0.235` 是真实 ChemDraw 输出测得的保守阈值；切换区间约为 `0.235–0.237`。
- 若任一轮廓超过该限制，则该 pair 不生成长尖角。两根键分别使用自己在节点处的轮廓 base，形成节点 bevel；不得把交点裁到某个固定距离，也不得把两根轮廓 base 取中点后强行共享一个顶点。
- 对等宽、夹角为 `φ` 的两根键，理论 miter 轴向长度为 `m = halfWidth / tan(φ / 2)`；仍须经过上述相对长度限制。

### 三根及以上键接触

规则：

1. 先按节点周向顺序排列 incident bond。
2. 只处理相邻 pair，不处理所有组合。
3. 每一对相邻键的内侧轮廓线求交，形成节点周围的一圈交点。
4. 每根键吃自己那一段端点轮廓链。
5. 三键节点中，实键可能自然变成五边形；更多键时，顶点数继续增加。

补充：

- 多键节点只处理相邻 pair，不处理所有组合。
- 非相邻 pair 的交点不得用于节点中心拓扑。
- 如果某类键被定义为“保持原样”，则该键不参与节点中心占位；由其他键退让。

### 直通例外

- `180°` 直通不强求交点。
- centered double 在夹角大于 `162°` 时不延长。

## 单键与粗实键

- 普通单键和粗实键都按四边形渲染。
- 二者只在宽度参数上不同。
- 接触时，它们都属于主键接触对象。

## 配位键

- CDX/CDXML `Order="dative"` 使用普通线宽箭杆与实心凹尾箭头，不进入锲形键规则。
- 设裁剪后的键长为 `L`、普通线宽为 `LW`，箭头长度严格为 `min(10 * LW, 2L / 3)`。
- 箭头底边半宽为箭头长度的 `1/4`；凹口位于从箭尖向后 `7/8` 个箭头长度的位置。
- 箭杆必须终止于凹口，不得继续延伸到箭尖，也不得在受体端参与普通键接触；供体端仍按普通主键规则接触。
- 这套几何只依赖 `LineWidth` 和实际可见键长，不依赖 `BoldWidth`、字体或名义 `BondLength`。规则来自不同方向、`5–100pt` 键长、四组 `LineWidth/BoldWidth` 的 ChemDraw SVG 静默测量。


`MarginWidth = 0` 是有效的源设置；文档规范化、编辑默认值、对象设置和导出均须保留零值，只有缺失或无效的留白才回退到默认值。

## 普通虚键

- 普通虚键的母体仍然是一根标准矩形主键。
- 白色切段沿主轴等距布置。
- 接触以母体矩形为准。
- 黑色段长度可以随 dash 规则变化；普通虚键不要求像 hash 家族那样“黑段严格等长”。
- 设可见轴线长为 `L`、源 `HashSpacing` 为 `h`，黑段数为 `floor(L / (2.6 * h)) + 1`，沿轴线等分为 `2 * 黑段数 - 1` 个黑段/空隙，首尾均为黑段。独立对照覆盖三种间距、五种长度、三种线宽及段数跳变边界。
- 端点接触 profile 只改变首尾黑段外形，不改变区间分配范围；profile 向内或向外伸入的部分都不应平移内部空隙。九个不同长度及接触角度的独立对照保持同一相位。端点 profile 属于首尾黑段，不是额外粘贴的独立端帽。
- `Display="Dash"` 仍是必须无损保存和导出的源样式；但当且仅当单键两端都是带直接子 `<fragment>` 的 `NodeType="Fragment"` 折叠片段节点时，ChemDraw 的可见主线按实线绘制。任一端不是这种结构时仍绘制普通虚键。`BS="N"` 是对称性已判定的 CIP 立体字段，`BeginAttach`/`EndAttach` 是文本字符连接索引，二者均不参与这条显示规则。该结论来自 ChemDraw 静默 A/B：改变外键 `Display`、内部连接线型、附件索引或补全连接映射均不改变实线结果；移除任一端的直接子片段后，同一外键稳定恢复为 15 段虚线。

### 非键虚线与直线实心箭头

采用实心箭头几何的非键直线使用重复短划。虚线从退让后轴线的 Head 侧向 Tail 侧排列，即使两端均无箭头也遵循此方向。短划长度取整到最近的 1/20 磅绘图单位；保留未取整间距会在长线中累积明显的相位偏差。只改变轴线的绘制顺序，不改变语义端点或箭头几何。独立 ChemDraw 对照覆盖三种长度、两个方向、四种首尾箭头组合及八种小数间距；普通化学虚键仍采用上文的区间分配规则。

## 哈希键

哈希键是单独的粗实母体加白色切段模型：

- 母体始终是粗实矩形。
- 黑色段长度必须一致。
- 白色段允许在一定范围内波动。
- 只有当总长超出当前段数允许的范围时，才增减白色段数量。
- 黑色段的长度优先级高于白色段的等距性。

### 哈希键与普通主键

- 保持标准矩形，不主动变形去贴其他键。
- 如果节点是多键节点，其他键退让，哈希键保持原样。

### 哈希键与 centered double

- 不求交，不改矩形端帽。
- 只沿哈希键自身中心线退让。
- 退让参考是 centered double 正确那一侧的外线。
- 白色切段跟随退让后的实际矩形，不沿旧长度切。

## 实锲形键

- 母体是梯形。
- 宽端宽度固定，窄端宽度固定为很短的顶边。
- 宽端在普通主键接触中允许按轮廓求交变形。
- 宽端如遇 label，实锲形键只使用中心线裁剪后的端点；不得再给实锲形键增加宽端额外退让。
- 长度变化时，应优先保持端宽定义，再更新梯形侧边。

## 虚锲形键

- 母体是标准梯形。
- 黑色段沿梯形主轴排布。
- 每条黑色段沿主轴的长度严格等于一个 `LineWidth`。
- 第一条和最后一条黑色段分别贴住最终梯形的两个端点。
- `HashSpacing` 是黑色段中心距的下限。ChemDraw 在满足该下限的前提下取最多段数，再把各段中心在两端之间均匀排布：

  ```text
  段数 = max(1, 1 + floor((最终键长 - LineWidth) / HashSpacing))
  中心距 = (最终键长 - LineWidth) / (段数 - 1)   （段数 > 1）
  ```

- 该规则来自对 Default、ACS、不同线宽和不同 `HashSpacing` 的静默 ChemDraw SVG 密集测量。不得复用普通虚线键的分配器，也不得对短虚锲形键强制至少画两段。
- 任一端遇到 label 时，裁剪规则与实锲形键一致：只使用中心线裁剪后的端点，不额外增加宽端或 hash 家族退让。

### EMF 键重放规则

ChemDraw 在 dual EMF 中会把普通键重新绘制为 pen，而不是保留场景渲染器使用的填充几何。普通键的 pen 宽度严格等于 `LineWidth`，起止端帽为圆帽，连接方式为 miter、miter limit 为 `2`，虚线端帽也为圆帽。GDI 兼容记录使用“几何 pen + 圆端帽 + miter join”（`EXTCREATEPEN` style `73728`）；round join 与该规则不等价。

虚锲形键在 EMF 中也会被重新绘制。每条黑段各自变成一条垂直于键轴的独立 pen stroke，并使用与普通键相同的 pen 属性，不写成填充四边形。设最终楔形长度为 `L`、线宽为 `LW`、粗线宽为 `BW`，条数沿用上面的公式，则：

```text
s_i = LW / 2 + i * (L - LW) / (count - 1)
W(s) = LW + (1.5 * BW - LW) * s / L
```

`s_i` 是从窄端起算的黑段中心位置，`W(s_i)` 是该处的横向中心线长度。因此，EMF 首尾中心线是在两端各向内半个 `LineWidth` 的位置采样，并不直接等于楔形端点宽度。若 `count = 1`，场景渲染器仍提供完整的短梯形，但直接 EMF 重放只在 `s = L - min(L, LW) / 2` 处取样，也就是从宽端向内半条黑段。恢复键轴前必须先应用对象的平移、旋转和缩放。

ChemDraw 的 Office/OLE presentation EMF 是另一套输出 profile；即使来自同一 ChemDraw 版本，它也不是 `SaveAs(.emf)` 的同一份字节流或同一套重放策略。在 Office profile 中，接近正方形的窄端黑段（横向中心线不大于 `1.25 * LineWidth`）会被重放成沿键轴方向的圆头 pen，pen 宽和中心线长度都等于 `LineWidth`。因此，在接近竖直的虚锲形键上，它会表现为 PowerPoint 中看到的短竖线。更宽的黑段仍保留为填充四边形。独立 EMF 文件导出必须使用上面的直接输出 profile；剪贴板/OLE presentation 和 Office 预览媒体必须使用 Office profile。

可复用的本地探针覆盖 3 组样式、9 种长度（包括只剩一条黑段的极短键区间）、4 个方向，以及普通键和虚锲形键，共 216 份 ChemDraw EMF：

```bash
node scripts/chemdraw-emf-bond-probe.mjs --verify-chemsema
```

探针检查记录类型和数量、pen flags 与端帽、归一化几何，以及不受 EMF 画框尺寸影响的 ChemDraw/ChemSema 一致性。

### 虚锲形键与普通主键

- 保持标准梯形，不主动求交改宽端。
- 多键节点中，优先保持自身母体形状，由其他键退让。

### 虚锲形键与 centered double

- 不宽端求交。
- 只沿虚锲形自身轴线退让。
- 宽端宽度保持固定，因此长度变化后梯形会自然变形。
- 白色切段必须跟随退让后的实际梯形。

## 单侧双键

单侧双键由一根主键和一根副线组成。为兼容 CDXML 间距，`bondSpacing` 是作用于实际键长的百分比，但 ChemDraw 还会施加线宽下限。内间距为：

```text
max(实际键长 * bondSpacing / 100 - lineWidth, 1.5 * lineWidth)
```

中心距为这个内间距再加两条实际渲染线宽各自的一半。若两条线都是普通线，可简化为：

```text
max(实际键长 * bondSpacing / 100, 2.5 * lineWidth)
```

这不是样式模板分支：ACS、Default 和自定义 CDXML 文档都使用同一规则，只代入源文件中的 `LineWidth`、`BondLength` 和 `BondSpacing` 数值。

`bondSpacingAbsolute` / CDXML `BondSpacingAbs` 的行为不同：它表示以 pt
为单位的精确中心距，优先于百分比，而且不施加线宽下限；即便明确写入的
绝对距离小于线宽，也仍然原样使用。

### 自动侧别判定

当 CDXML 或编辑操作只给出 `Order="2"`，但没有显式 `DoublePosition` 时，应按 ChemDraw 规则自动判定：

1. 若该键属于环，则先按环选择规则决定参考环，再把副线放在该参考环内部：
   - 完整交替的六元环优先于更短的稠合小环。
   - 之后依次比较是否完整交替、交替匹配数、是否接近六元环、路径长度。
2. 对每根附属键先把方向单位化，再计算它在 begin→end 左法向上的有符号分量
   `s`。`|s| < 0.2146` 时，ChemDraw 把它视为相对双键轴近共线，不让它支持
   左右任一侧；实测转折位于 `12.3899°`（不计）与 `12.3950°`（计入）之间。
   该阈值不随实际键长、`BondSpacing`、`BondSpacingAbs`、线宽或整体旋转变化。
3. 相邻键本身是双键或芳香键时，普通端点覆盖之前另有一个更窄的累积双键分支：
   - 相邻双键方向的归一化法向分量小于 `0.173691`（实测转换区间的中点）时，目标双键居中；即使另一端还有斜向单键也不改变。
   - 实测转折位于 `10.002°`（居中）与 `10.003°`（选侧）之间，且不随整体旋转或
     15–60 pt 的相邻双键长度变化。
   - 超过该阈值的弯折共轭链恢复普通附属键的端点覆盖规则。
4. 左右两侧分别统计“至少有一根有效附属键”的双键端点数，取值只能是 0、1、2：
   - 统计的是覆盖了几个端点，不是附属键数量、键长、投影长度和或元素/CIP 优先级。
   - `BS=E/Z` 与 `BondCircularOrdering` 保存立体语义，不参与副线侧别；节点坐标完整时，
     官方定义也把 `BondCircularOrdering` 视为与坐标冗余。
5. 两侧都没有有效附属键时，使用 centered double。
6. 某个 terminal 端左右两侧都有有效附属键、另一端没有有效附属键时，使用 centered double。
7. 其余情况选择端点覆盖数更大的侧；覆盖数相同且处于新增附属键编辑操作时，使用
   新增有效附属键所在侧；没有编辑上下文或新增键仍属近共线时，默认 `Right`。

一般矩阵由 `scripts/chemdraw-double-bond-side-probe.mjs` 复核；
`scripts/chemdraw-aromatic-chain-side-probe.mjs` 另行覆盖带末端斜向单键的
`10.002°/10.003°` 累积双键转折、弯折共轭链、芳香 `Order="1.5"`、显示样式、旋转、
键长、镜像、B/E 反转以及 `BondCircularOrdering` 不参与侧别。
两者都静默调用 ChemDraw，并直接按输出 SVG 中主线/副线相对位置判定。显式
`DoublePosition` 始终优先，并冻结自动侧别。

### 主键

- 主键属于普通主键接触对象。
- 与单键、粗实键、三键、楔形等按主键接触规则处理。

### 副线

- 外副线默认保持原样，不参与普通接触。
- 内副线才参与接触求交。
- label 端点裁切时，主键和副线必须沿各自实际平移后的轴线、按各自 half-width
  分别计算退让，再共同采用较大的退让量；不得从未平移的中心线推导两者。
- terminal 端与主键等长。
- 非 terminal 端按“与主键间距 * `sqrt(3) / 3`”缩短。
- 当主键与连接主键夹角小于 `90°` 时，副线允许退让；但如果对方存在同侧副线，则同侧副线仍然优先求交。

### 锐角退让

- 如果主键连接的是主键，且该侧夹角小于 `90°`，副线可退让。
- 但如果对方也有同侧副线，则同侧副线仍然直接求交。
- 如果对方副线不在同侧，则按退让处理。
- 如果遇到 centered double，则以 centered double 的中心线作为退让参考。

## centered double

centered double 由两根独立子线组成。

规则：

- 每根子线各自判断各自端点。
- 遇到 label clipping 时，两根子线必须沿各自实际偏移后的轴线，并按各自实际
  half-width 分别计算端点退让；每个端点取两根子线所需退让量的较大值，再把该
  退让量同时应用到两根子线上，使最终两根线保持等长。
- 不得先在未偏移的中心线上计算退让，再把中心线结果复制或平移给两根子线。
- 每端、每侧独立决定是否延长到其他键的轮廓。
- 大于 `162°` 的近直通情况不延长。
- `180°` 直通保持原样。
- 与 hash 家族接触时，centered double 是被参考的一方，不反向改 hash 家族外框。
- 适用于：
  - 实实中心双键
  - 虚实中心双键
  - 双虚中心双键

## 三键

- 中线位于键轴上，两根外线使用与普通线宽双键相同的中心距：

```text
max(实际键长 * bondSpacing / 100, 2.5 * lineWidth)
```

- 这里使用实际端点距离，而不是文档名义 `BondLength`，并且与键方向无关。
- 三键上的 `bondSpacingAbsolute` / CDXML `BondSpacingAbs` 不沿用单侧双键
  的规则。ChemDraw 22.2 会保留该字段，但只要该字段存在，三键绘制就同时
  忽略它和文档明确写入的 `BondSpacing`，改用
  `max(实际键长 * 15 / 100, 2.5 * lineWidth)`。
- 可复现的 ChemDraw SVG 探针覆盖三种键长、三种百分比间距、三种线宽、
  水平/斜向/竖直方向、3 种线宽乘 7 种绝对值的矩阵，以及三种键长乘三种
  文档百分比的绝对字段样例：

```bash
node scripts/chemdraw-triple-bond-spacing-probe.mjs
```

- 三键主线属于主键接触对象。
- 两根外线各自独立判断自己的端点 profile。
- terminal 端以及与普通单键相接的端点，外线都保持原始轴向全长。普通单键
  不得把单侧双键的角度退让公式套到三键外线上；静默 ChemDraw 探针已经覆盖
  `30°` 到 `330°` 的各代表方向。主线仍可独立延伸到节点接触轮廓。
- 只有相邻多重键确实提供同侧外线轮廓时，显式的外线接触 profile 才能改变
  对应端点。

## 多键节点中的 hash 家族优先级

若一个节点同时接多根键，并且其中有 `hash bond` 或 `hashed wedge`：

- `hash bond` / `hashed wedge` 保持原样。
- 其他键退让。
- 故意留一点白，不做完全无缝贴合。

## 判定优先级

同一个端点如果同时命中多条规则，应按以下优先级处理：

1. label clipping
2. hash 家族保持原样规则
3. centered double 近直通不延长规则
4. 主键接触求交
5. 单侧双键副线同侧求交
6. 单侧双键副线锐角退让
7. terminal 等长 / 端部固定长度规则
8. dash / hash knockout 切段

后面的规则不得推翻前面已经确定的几何拓扑，只能在剩余自由度内继续收紧。

## Label 与裁切

- CDX/CDXML 的 `BeginAttach`、`EndAttach` 若指向结构节点 label 内部的连接
  原子/glyph，则它们是权威端点锚点。导入必须把它们解码为
  `meta.endpointAttachments.<endpoint>` 下包含 `target`、`characterIndex` 和
  `character` 的语义对象；渲染时必须从当前 label glyph geometry 解析真实端点，
  不能继续使用结构 label 外层节点的位置。
- 若端点锚点字段不存在、越界，或无法在当前 glyph geometry 中解析，则已有键的
  端点保持在结构节点坐标。该坐标决定主键轴线；label clipping 可以让可见线段从
  该坐标退让，但不得把轴线移到附近某个 glyph 上。
- 侧双键终端 label 没有显式端点锚点时，默认连接 glyph 必须布局在结构节点/主键
  轴线上；平行副线的间距绝不能让 label 偏移半个双键间距。
- 显式固定的 `LabelDisplay="Left"` / `"Right"` 锚定作者写入的边缘，而不是
  就近的普通基线字符。位于首尾的下标参与边缘锚定；上标不参与，必须向内寻找
  第一个/最后一个非上标字符。自动化学布局仍排除自动生成的上下标连接锚点。
- 导出必须把保留的端点锚点写回 CDX/CDXML，确保 open-save-open 后文件稳定。
  应用内部锚点时不得为了让键轴看似对齐而移动另一端原子。
- 节点有可见 label 时，优先先做 label clipping。
- label clipping 发生在 bond contact 之前。
- 标签退让沿端点射线求解，不得钳制在原键线段内。如果源文件中的键短于标签，
  标签排除边界可能越过另一端原子；此时保留越界后的端点，最终可见键身会反向。
  两端退让量也不得按原键长等比缩回。裸 CDXML 的连续键长探针在越界前后保持严格
  线性，`NeedsClean` 不改变该行为。
- 上述反向规则适用于只有一端标签排除边界越过键长的情况。如果两端都有标签，且
  两端排除距离已经相接或交叉，ChemDraw 会把键身宽度压为零，因此不产生可见墨迹。
  单键和双键的连续间距探针都保持这一分支。
- 端点标签裁剪只执行一次。由无界端点射线得到的键身即为最终裁剪结果，不得再拿
  已经反向的端点重复裁剪。
- 键最终 geometry 应同时满足 label 裁切和节点接触规则。
- 对同一行的多字符 label，首字符仅把朝向组合内部的半边矩形化，末字符同理；
  每个中间字符只使用该字符自己的矩形边界，外侧半边仍保留真实字形轮廓。
- 相邻字符之间只在两者实际垂直重叠的高度范围内补内部矩形。不得使用整行共享的
  最低点或最高点；较低的括号、下伸部不得把另一个字符的裁切矩形向下拉平。
- 下标和上标字符不参与这套同一行内部矩形连接。
- ChemDraw 的窄轴向接触扇区按横排文字的书写轴分支。与竖轴夹角不超过 `10°`
  的键射线按字形列归属；与横轴夹角不超过 `10°` 的射线使用覆盖完整文字段的统一
  左右包络，而且该扇区内由包络替代一般的 natural/feature 轮廓核；斜向接触使用
  完整标签轮廓。横向字形位置必须先应用所选字体 face 的真实 kerning；
  `BeginAttach`/`EndAttach` 只选择射线起点对应的作者字符，不改变包络边界。
  上下归属由键中心线和两条键身边界射线实际穿过的原始
  字形区间决定；`MarginWidth` 只外扩已经选中的字形裁剪轮廓，不能让相邻字形抢走
  该列。朝向大写字母顶端的一侧采用所选字形自身的顶边；朝向基线下方的一侧采用与
  所选字形排版基线完全相同的整个 run 的下降部包络，偏移基线的上下标仍是独立
  run。如果竖向射线恰好落在字偶间隙，则沿射线方向把间隙归给最近字形。公开样例
  `3060_iso_butane.cdxml` 验证纵向分支：`CH3` 下方竖键按 `C` 所在列结束
  （ChemDraw 中 `y = 191.09pt`），不能被右侧下标 `3` 的更低边缘继续裁短；
  公开样例 `0137` 中反复出现的 `(CH2CHO)m` 等固定方向标签则验证横向整段包络。
  同基线 `T/Tyr` 探针验证纵向两侧并不对称：顶侧端点相同，底侧 `Tyr` 端点必须
  纳入 `y` 的下降部。
- 双键或三键的平行子线共享完整标签轮廓所要求的退让量，不能把单线的竖向字形列
  分支分别套到每根子线上；因此偏移的化学上下标可以决定这些子线的共同端点。
  三键的共同切面取三条轨道中心线射线与该轮廓交点中的最远值，不随 `LineWidth`
  外扩；ChemDraw 在 `0.2` 到 `4 pt` 的探针中，即使轨道间距已受线宽下限控制，
  轴向端点仍保持不变。

## 键键交叉与白边

非端点键键交叉指两根键在内部线段相交，但不共享 begin/end 节点。这个规则只处理键与键，不处理键与文本、键与 shape、键与箭头。

规则：

- CDX/CDXML 的 `CrossingBonds`（CDX property `0x060E`，类型 `CDXObjectIDArray`）使用文档全局对象 ID 作用域，是交叉 pair 的权威语义；两个键即使位于不同 fragment 也可以互相引用。导入必须保存，导出必须按新对象 ID 重映射并写回。只要 pair 任一侧存在显式 crossing 列表，就不得为列表之外的几何相交补造交叉；双方都没有该字段时才允许几何回退。
- 交叉计算必须使用与最终键体绘制完全相同的端点。若 `BeginAttach`/`EndAttach` 指向标签内部字符，交叉轴从该字符的最终字形锚点出发，不能退回节点的原始 `p`；完整文档绘制、局部 target 重绘和对象依赖判定必须共用这一轴。否则上层键虽然画在字符锚点上，下层缺口却会留在原始节点轴上。
- 上下层由最终绘制顺序决定：先比较 CDXML `Z`，同层再按文档顺序；后绘制者为上层键。
- 普通、正常线宽、实线单键相交时，ChemDraw 会把下层键体 polygon 在切断区间两侧直接裁成两段，而不是先画完整键再覆盖白色。内核必须输出同样的真实分段几何，避免白色覆盖层在抗锯齿边缘残留黑色细屑。
- 复合线、虚线、波浪线和锲形键使用各自明确的局部背景 knockout 分支，让下层键在交点附近断开。严禁复制整根上层键并扩大白色描边；整键遮罩会擦除同一路径附近的正常节点接触和其它结构。
- 白边宽度使用上层键的模板参数：Default 为 `2.0pt`，ACS Document 1996 为 `1.6pt`。
- 设 `n = (-axis.y, axis.x)` 为上层键的单位法向量。先求交点处沿 `n` 的 ChemDraw 切断包络 `[c_min, c_max]`，再按源 margin 外扩；knockout strip 严格为 `[c_min - marginWidth, c_max + marginWidth]`，不要求相对母键轴线对称。
- 普通实线和粗实线以可见键体轮廓作为 `[c_min, c_max]`；锲形键采用交点处线性插值后的局部轮廓。复合线族则使用各子线中心线的包络：居中双键和三键取最外侧子线中心，侧置双键取主线与侧线中心。波浪键取波浪中心路径的极值。复合线/路径包络不得再次加入子线条的半线宽，因为局部 knockout 之后还会重绘上层键。
- 波浪键由四分之一椭圆三次贝塞尔段组成，横向半径为 `BoldWidth / 2`。ChemDraw 的轴向相位网格来自文档默认值，而不是每根键自身：`网格数 = clamp(round(BondLength / LineWidth), 12, 16)`，`网格步长 = BondLength / 网格数`。随后仅在下一个网格点仍位于实际键长内时继续绘制，因此在 `30pt` 模板中，`29.998pt` 的键会有意比 `30.000pt` 的键少一个末段。下限规则只有一个且可泛化：若实际能容纳的网格段不足 12，ChemDraw 固定绘制 12 段，并把这 12 步重新均分到实际键长。每个控制柄的长度，等于与该端点切线垂直的半径乘 `0.5522847498307936`：中心线端点使用横向振幅，波峰和波谷端点使用轴向步长。
- 波浪键与标签相接时采用独立的相位分支，但保留已经测准的标签方向扇区：水平接触使用专用行包络，斜向接触使用完整字形轮廓，只有上下基准扇区才通过波形条带选择字形列。在这个上下分支中，先把字形几何按 MarginWidth 外扩，再与可见波形扫过的连续横向条带相交；条带半宽为 `BoldWidth / 2 + LineWidth / 2`，不能只用中心和两侧三条射线近似。连续条带能触达 `R2` 中邻近的下标 `2`，又不会让横向长标签按整块文本矩形退让。裁剪后使用 `段数 = clamp(ceil(裁剪后长度 / 网格步长), 1, 网格数)`，并把这些段均匀铺满裁剪后的长度。这里不套普通波浪键的 12 段下限：ChemDraw 实测路径可以只有 9 段或 11 段，末端也可以停在波峰或波谷，而不一定回到中心线。
- 因此，中心距为 `d` 的居中双键使用 `[-d/2, d/2]`；左侧双键使用 `[0, d]`；右侧双键使用 `[-d, 0]`，左右方向以 `n` 为准。侧置双键必须保持这个非对称区间；若强行对称，会在没有第二条线的一侧多擦掉下层键。
- 在对称特例 `[c_min, c_max] = [-h_over, h_over]` 中，设两键锐角为 `θ`，下层键沿自身轴向的半切口长度严格为：

  ```text
  gapHalf = (h_over + marginWidth) / abs(sin(theta))
  ```

- 切口两条边必须平行于上层键。普通实线单键直接用这两个半平面裁剪下层 polygon；局部 knockout 分支的另两条边只负责把遮罩限制在下层键的完整可见轮廓内，不能沿上层键延伸到整根键。抗锯齿余量只能加在 knockout 的下层轮廓限制边上，不得扩大上层键的切断区间。
- 共享端点的键仍走节点 contact kernel，不使用这个白边规则。
- 对中心线内部相交，交点仍须同时位于两根有限线段内部，并使用上面的局部 strip 规则。
- ChemDraw 还会检查上层键的**有限 margin 包络**是否碰到下层键轮廓：横向两侧各外扩 `marginWidth`，并在键轴方向越过两个 butt cap 各延伸 `marginWidth`。因此，即使两根有限中心线没有真正相交，端点附近的擦边也可能削短下层键或切出缺口。此时只渲染该有限包络与下层可见轮廓的交集，不能把无限白色 strip 贯穿文档。
- 共享端点仍属于节点 contact；近乎平行或重合的键不进入这条端点邻近交叉规则。

## Default 圈电荷符号

- Default 风格的 `CirclePlus` / `CircleMinus` `BoundingBox` 是定位锚框，不是圆的中心线直径。圆直径等于锚框高度减 `0.30pt`；往返导出时仍保留原始锚框。
- editing scale 为 1 时，内部正负号相应的宽/高为 `5.444pt`，线宽为 `0.8pt`。这些数值属于符号模板参数，不得从位图反推。

## 预览

- 拖动画键时不画假的 overlay bond。
- 预览态通过临时文档调用同一套 `render_document`。
- 因此预览和落地必须共享同一套接触几何。

## 重构约束

后续拆分 `render` 模块时，应保持以下约束：

- 不改变本文档中的几何规则。
- 优先拆高层调度与低层几何，不在一次重构里继续改规则。
- 每次拆分后必须通过：
  - `cargo test`
  - `npm run build:engine-wasm`

## 测试基线

以下几类规则必须至少有一层自动化测试覆盖：

- 主键接触侧别判定和直通判定。
- centered double 的 `162°` 阈值。
- miter limit 截断后的求交回退。
- hash 家族“黑段等长、白段浮动”的节奏分配。
- boundary pairing 不得错误选择 trivial assignment。
- 多键节点中 hash 家族保持原样、其他键退让。

建议测试分层：

- 低层单测：直接测求交、侧别、节奏分配 helper。
- 渲染级测试：测输出 primitive 的数量、类型、关键顶点关系。
- 前台验证：只负责确认 viewer 没有 stroke / AA 伪影，不负责定义几何。

## 范围边界

- SVG 抗锯齿细节由具体渲染后端处理。
- 不同浏览器的像素级差异由视觉回归容差处理。
- debug 面板、调试 SVG、开发期 patch 属于开发工具。

## 关联电子符号与分组

- CDXML 的 `represent` 表示符号体现原子属性，不应把已有属性再加一次。自由基离子符号可以通过 Charge 或 Radical 任一字段同时表示电荷与自由基；导入和后续化学属性刷新统一使用 `ElectronSymbolChemistry::represents_attribute`。
- 电子符号的化学处理遍历嵌套组。符号进入组后，与原子的关联、电荷、自由基数量及附着信息在重新加载后仍须保留。
- 绘制不能把“属性增量为零”当作“没有符号”。表示已有自由基的符号仍提供可见圆点，不应额外生成原子注释；孤对电子则不能隐藏未成对电子的注释。
- 分组导入覆盖嵌入图片、受支持的特殊对象，以及片段内独立的图形或文本；不进入原子拥有的隐藏缩写定义。
- `tests/cdxml_groups.rs` 覆盖嵌套归属、原生/CDXML 往返、复合符号、重复加载，以及孤对电子与自由基的区别。
